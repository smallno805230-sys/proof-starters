極限點

例題：令 A = {1/n | n 為正整數}，證明 0 是 A 的極限點。

題型辨識

看到「證明 0 是極限點」，先任取半徑 ε > 0，再找一個距離 0 小於 ε、而且不同於 0 的 A 中元素。

英文起手式

Let ε > 0 be arbitrary. We will find a point x in A such that 0 < |x| < ε.

先任取 ε，因為每個半徑都要成立。條件 0 < |x| 確保找到的點和 0 不同。

證明步驟

  1. 由阿基米德性質，選一個正整數 n，使 n > 1/ε。
  2. 令 x = 1/n，則 x ∈ A，而且 0 < |x| = 1/n < ε。
  3. 因此，對每個 ε > 0，區間 (−ε, ε) 都含有一個不同於 0 的 A 中元素，所以 0 是 A 的極限點。

常見錯誤

只選 n = 10。這時 x = 0.1，若 ε = 0.01，x 就落在區間外。先任取 ε，再依 ε 選出滿足 n > 1/ε 的正整數。
